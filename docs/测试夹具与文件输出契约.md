# Office 真实文件构造提示

每个文件只验证一个功能，文件中不要加入未列出的对象。

## 通用步骤

1. 使用桌面版 Word、PowerPoint 或 Excel，不使用网页版。
2. 新建空白文件，只执行表格中的操作，使用固定英文文本、固定数字和固定日期。
3. 禁用随机函数、当前时间、自动更新字段、外部链接、实时数据连接和远程图片/媒体。
4. 保存为 `.docx`、`.pptx` 或 `.xlsx`，关闭文件后重新打开，确认 Office 能正常读取，再复制到对应目录。
5. 若一个操作会自动附带其他对象，只保留完成该功能所必需的对象；不要为了美观加入额外页面、图形或装饰文本。
6. 重新保存同一文件时保持 Office 版本不变。批注作者固定为 `Reviewer`，链接固定为 `https://example.test`，日期固定为 `2026-08-01`（能设置时）。

列表编号样式使用已验证的简体中文 Word 默认样式文件；多级列表、无可见编号列表和项目符号单独验证列表结构或项目符号行为。
